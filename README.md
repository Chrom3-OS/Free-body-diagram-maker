# Free Body Diagram Maker

An interactive web application for creating accurate free body diagrams for AP Physics 1. Create, edit, and export professional-quality physics diagrams with customizable forces, colors, and shapes.

## Features

- **Interactive Canvas**: Draw and manipulate objects and forces on a grid-based canvas
- **Multiple Object Types**: Add boxes and circles to represent different physical objects
- **Common Force Types**: Pre-configured force types including:
  - Gravitational Force (Fg)
  - Normal Force (FN)
  - Friction Force (Ff)
  - Tension Force (FT)
  - Applied Force (FA)
  - Custom Forces
- **Full Customization**:
  - Editable force colors, magnitudes, and angles
  - Adjustable arrow styles (filled or outline)
  - Customizable object colors and sizes
  - Editable force labels
- **Accurate Measurements**:
  - Precise angle control (0-360 degrees)
  - Adjustable force magnitude/length
  - Grid system with snap-to-grid option
  - Optional angle display
- **Professional Output**:
  - Clean, publication-ready diagrams
  - Export to PNG format
  - Grid toggle for presentation

## Usage

1. Open `index.html` in a web browser
2. **Add Objects**: Click "Box" or "Circle" buttons to add objects to the canvas
3. **Add Forces**: 
   - Click a force type button (Gravity, Normal, etc.)
   - Click on an object to attach the force to it
4. **Edit Properties**:
   - Click on any object or force to select it
   - Use the properties panel on the right to customize:
     - Colors
     - Sizes/Magnitudes
     - Angles
     - Labels
     - Arrow styles
5. **Move Objects**: Click and drag objects to reposition them
6. **View Options**:
   - Toggle grid display
   - Enable/disable snap-to-grid
   - Show/hide angle measurements
7. **Export**: Click "Export PNG" to save your diagram as an image
